# writerdeck
mi propio setup para un writerdeck, basado en debian 13

este pedacito de software se entrega sin ninguna garantía, a menos que seas mi novia 

# instalación
1. instala debian 13 en un computador de 64 bits (versión 32 bits saldrá en algún momento)
2. instala git
```
sudo apt install git -y
```
3. descarga y abre el instalador
  ```
git clone https://github.com/synthorlando/writerdeck.git
cd writerdeck
chmod +x install.sh
./install.sh
  ```
